# Watch Supreme

Витрина магазина оригинальных часов с пробегом. Статический сайт без сборки: HTML, CSS и JS.

## Как посмотреть локально

```
cd grand-watch
python3 -m http.server 8000
```

Откройте http://localhost:8000. Если открыть `index.html` двойным кликом, каталог не загрузится: браузер не даёт читать файлы с диска.

## Что где менять

| Что | Где |
|---|---|
| Имена и Telegram партнёров, срок брони, город | `config.js` |
| Часы в каталоге | Google Таблица «Watch Supreme — учёт», лист «Товары» (`data/watches.json` — запасная копия) |
| Фото часов | `photos/<артикул>/1.jpg, 2.jpg…` |
| Тексты: первый экран, шаги, FAQ | `index.html` |
| Цвета и шрифты | начало `assets/css/style.css` |

## Поля одной позиции (`data/watches.json`)

- `id` — артикул, например `W-008`. Ссылка на часы: `сайт/#w/W-008`.
- `brand`, `collection` (по ней работает фильтр-чипсы), `model`, `reference`, `year`, `diameter` (мм).
- `material`, `movement`, `dial`, `condition`, `description` — текст.
- `box`, `papers` — `true` / `false`.
- `price` — в рублях, `0` = «Цена по запросу».
- `status` — `available` (в наличии), `reserved` (забронировано), `sold` (продано).
- `featured: true` — показывать на первом экране.
- `photos` — список путей, например `["photos/W-008/1.jpg", "photos/W-008/2.jpg"]`. Первое фото — обложка.
  Пока фото нет, рисуется схематичный циферблат цветом `dialColor` с безелем `bezelColor`.

Фото: квадратные или 4:5, примерно 1600 px по длинной стороне, JPEG до ~400 КБ.

## Публикация

Сайт живёт на хостинге reg.ru (https://watch-supreme.ru). Выкладывает его GitHub Actions (`.github/workflows/deploy.yml`) по FTP:

- после каждого push в `main`;
- каждые 15 минут — чтобы подхватить изменения из Google Таблицы;
- вручную: Actions → «Deploy to hosting» → «Run workflow».

Нужны секреты репозитория `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`. Фото можно класть и прямо по FTP в `photos/W-00X/` — выкладка их не удалит.

## Google Таблица

Таблица [«Watch Supreme — учёт»](https://docs.google.com/spreadsheets/d/1-vAnHSq7GuFNFfnYNLmUqNNaWXAt39atc5m-usRYltY/edit):

- **Товары** — по строке на часы. Зелёные колонки идут на сайт (если «На сайте» = да), оранжевые видите только вы, серые считаются сами.
- **Расходы** — общие траты: реклама, упаковка, домен.
- **Переводы** — деньги, которые партнёры передают друг другу при расчёте.
- **Сводка** — выручка, прибыль, деньги в товаре и баланс каждого партнёра.

### Как подключить таблицу к сайту (один раз)

1. В таблице: «Расширения» → «Apps Script».
2. Удалите всё в редакторе и вставьте содержимое `apps-script/Code.gs`. Сохраните.
3. «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение».
   «Запуск от имени»: я. «У кого есть доступ»: все. Нажмите «Начать развертывание» и разрешите доступ.
4. Адрес веб-приложения (`https://script.google.com/macros/s/…/exec`) записан в `deploy.yml` (`SHEET_URL`). Если он поменяется, задайте новый в переменной репозитория `SHEET_URL` (Settings → Secrets and variables → Actions → Variables).

Посетители в Google не ходят: перед каждой выкладкой GitHub забирает у скрипта публичные колонки и кладёт их на хостинг как `data/watches.json`. Изменения в таблице появляются на сайте в течение ~15 минут. Если таблица не ответила, выкладывается копия `data/watches.json` из репозитория.
